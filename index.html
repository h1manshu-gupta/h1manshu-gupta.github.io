01 · Natural Language Processing

Email/SMS Spam Classifier

An end-to-end NLP pipeline that classifies messages as spam or ham, from raw text preprocessing to a deployed web app.

PythonNLTKScikit-learnTF-IDFNaive BayesStreamlit
  • Preprocessed text with tokenization, stopword removal, and stemming; compared CountVectorizer and TF-IDF features.
  • Evaluated Decision Trees, Random Forest, and three Naive Bayes variants on Accuracy, Precision, Recall & F1-score.
  • Best model — TF-IDF + Bernoulli Naive Bayes — reached 98.84% accuracy and 95.24% F1-score.
  • Deployed as an interactive Streamlit web app for real-time message classification.
